PRIVACY INFORMATION · DRAFT

How the website handles information.

This draft explains what can be established from the public website code. The Cloudflare dashboard configuration, operator identity, contact method and real data-retention settings have not been verified, so this is not a final privacy policy.

Tools that run in your browser

Word Counter, Case Converter, JSON Formatter, Password Maker, URL Encoder and Text Cleaner transform data in your browser. Their input is not intentionally submitted to the site's backend in the current code. For Password Maker, random values are generated using the browser's secure random number generator.

Favorites are saved to localStorage on the device/browser you use. You can clear this preference using your browser's site-data controls.

AI Writer: prompts leave your device

When you select AI Writer and submit a prompt, the website sends that prompt to its Cloudflare Pages Function, which calls the configured Cloudflare Workers AI model. The prompt is processed to generate a response. Avoid supplying personal, confidential or sensitive information. AI-generated text can be incorrect.

The checked code does not create accounts or store submitted prompts in an application database. Its error handler logs a server-side error message when a model request fails, but is not designed to log the prompt text. The operator must verify all enabled Cloudflare logging, diagnostics, bindings and retention settings. No retention duration can be confirmed from code alone.

Other services and external websites

Cloudflare hosts the website and may process technical request information needed to serve pages and operate functions, according to its policies and the operator's configuration. Product logos currently use remote favicon services from Google or DuckDuckGo; viewing a logo may cause a browser request to those services. Selecting an Official site link opens a third-party website governed by its own privacy practices.

The checked repository does not include AdSense scripts or an analytics SDK. Cloudflare Web Analytics, request logs, AI Gateway or other optional services may be configured outside the repository and cannot be ruled out without reviewing the dashboard. This notice must be updated if additional services are active.

Operator and privacy requests

To complete this notice: confirm the operator’s public name or business identity and country, a private privacy-contact address, actual analytics and logging settings, enabled third-party integrations and verified retention periods. We have not invented any of these details.

Do not share personal or confidential information in public GitHub issues. General listing corrections and broken links can be reported through Contact. The operator must approve an accurate final policy.
