PRIVACY INFORMATION · DRAFT

How the website handles information.

This notice describes the behavior visible in the current website source code. It must be checked and completed by the site operator before a production privacy statement is considered final. We cannot independently confirm Cloudflare account configuration, log retention or any external services the operator might enable.

Tools that run in your browser

Word Counter, Case Converter, JSON Formatter, Password Maker, URL Encoder and Text Cleaner transform data in your browser. Their input is not intentionally submitted to the site's backend in the current code. For Password Maker, random values are generated using the browser's secure random number generator.

Favorites are saved to localStorage on the device/browser you use. You can clear this preference using your browser's site-data controls.

AI Writer: prompts leave your device

When you select AI Writer and submit a prompt, the website sends that prompt to its Cloudflare Pages Function, which calls the configured Cloudflare Workers AI model. The prompt is processed to generate a response. Avoid supplying personal, confidential or sensitive information. AI-generated text can be incorrect.

The website code does not add a user account or database for AI Writer prompts. That does not establish what logs, diagnostics or retention are configured by the hosting or model provider. These must be confirmed by the operator.

Other services and external websites

Cloudflare hosts the website and may process technical request information needed to serve pages and operate functions, according to its policies and the operator's configuration. Product logos currently use remote favicon services from Google or DuckDuckGo; viewing a logo may cause a browser request to those services. Selecting an Official site link opens a third-party website governed by its own privacy practices.

The current website source does not contain AdSense ad tags or an analytics SDK. If advertising, analytics or consent products are added later, this notice needs updating before activation.

Operator and privacy requests

Operator identity, private contact method, legal jurisdiction, retention periods and relevant processors: not yet provided or independently verified. These details are required to complete this notice accurately.

Until a private contact method is provided, do not send personal information in public GitHub issues. General website corrections can be reported through Contact.
