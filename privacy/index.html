Privacy and data handling.

This page explains what is verifiable from the website code and what still requires confirmation from the operator. The owner’s legal identity, private contact address and Cloudflare account-level data settings have not yet been supplied. The notice is not a finalized compliance statement.

Who operates AI Tools Hub?

AI Tools Hub is an independent AI discovery directory published at ai-tools-hub-882.pages.dev. A public legal operator name, country of establishment and private contact address are not yet confirmed. Visitors should not assume a particular company or jurisdiction. These details must be supplied before this notice can be finalized.

Six tools that run in your browser

Word Counter, Case Converter, JSON Formatter, Password Maker, URL Encoder and Text Cleaner work inside your browser. According to the checked JavaScript code, their input is processed locally rather than intentionally submitted to the site backend. Password Maker uses the browser's cryptographic random generator.

Favorite tools are saved in your browser's localStorage. You can remove that preference using the browser's site-data controls. This statement does not rule out normal browser/network requests to load the website itself.

AI Writer and model processing

When you submit text to AI Writer, your prompt is sent over the network to a Cloudflare Pages Function at /api/generate, which calls a Cloudflare Workers AI model through the configured AI binding. The model processes your text to produce a reply. The current application code does not intentionally store prompts in a user account or application database.

Cloudflare may process technical request information and service diagnostics; the account's logging, model processing and retention configuration has not been independently checked. Do not submit sensitive or confidential material. AI output may be incorrect.

Private contact form — only when enabled

The Contact page checks whether a private inbox is configured. Until the site owner enables it, the form cannot submit and no contact message is accepted. When enabled, it sends the name, reply email, inquiry category, subject and message to a Cloudflare Pages Function. The message is stored in a private Cloudflare Workers KV namespace for the site operator to review. A retention period is supplied by the operator in the CONTACT_TTL_DAYS environment setting, and the code applies automatic expiration. No duration is asserted here because the actual setting has not been confirmed.

Cloudflare Turnstile verifies the request to reduce automated spam. The form does not publish the message to GitHub or automatically send it to an email address. Public GitHub issue reports are handled by GitHub under its own terms; avoid personal details there.

Analytics, cookies and technical requests

The checked repository does not embed Google AdSense ad tags or a Google Analytics SDK. However, Cloudflare Web Analytics can be enabled and inserted through the hosting dashboard without a source-code change; whether it is active cannot be established from GitHub. The Cloudflare dashboard is also needed to verify request logs, technical retention and any other enabled integrations.

The site's own browser code uses local storage for favorites and does not intentionally set advertising cookies. Third-party widgets and infrastructure may have their own data handling. No behavioral advertising or cookie-consent platform is claimed to be active.

External websites and brand icons

Brand icons use Google's favicon service with DuckDuckGo as fallback when needed. Loading those resources may result in a browser request to the provider. Official-site buttons open other websites, which have independent privacy terms. The contact form, once configured, loads Cloudflare Turnstile as a separate anti-spam service.

Choices, corrections and privacy requests

You can clear favorite-tool preferences in your browser. If an AI response contains an error, do not rely on it for important decisions. To request correction of directory information, use Contact. Personal-data requests need a private contact channel, which the operator must provide; do not publish personal data in public GitHub issues.

Still required from the operator: public identity, country, privacy contact, analytics enablement, actual Cloudflare processing and log retention settings, any other active processors, the configured contact-message retention, and advertising/consent settings if ads are introduced.
